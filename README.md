# 한Việt LINK — TWO SIDES · Life Simulator v4.0

학교 구성원 간 언어·문화·역할의 차이를 이해하기 위한 시범 게임입니다. 실제 교직원들의 발언을 인용한 것이 아니라 상황을 각색한 교육용 이야기입니다.

## 실행 방법
- ZIP 압축을 해제한 뒤 `index.html`을 Chrome 또는 Edge 브라우저에서 엽니다.
- 별도 설치, 회원가입, API 키가 필요 없습니다. 게임의 진행·상점·업적·학습 기록은 **현재 브라우저의 localStorage**에 저장됩니다. 다른 기기나 브라우저와 자동 동기화되지 않습니다.
- SPEAK의 실제 녹음은 마이크 접근 권한과 보안 연결(HTTPS 또는 localhost)이 필요할 수 있습니다. 음성 인식은 브라우저별 지원 여부와 외부 음성 인식 서비스에 따라 동작이 달라집니다. 녹음·인식 기능은 실제 사용 전에 기기별로 확인해 주세요.

## 업데이트 v4.0
1. **교직원 루트 전면 재구성**: 베트남어 교사, 경비원, 급식실 직원, 미화 직원 중 직무를 선택하고 해당 직무로 6년을 진행합니다. 매 학년 해당 직무의 이야기 두 편과 공통 업무 사건 한 편이 선택 이벤트로 발생합니다. 실제 학교 규정은 확인 후 반영해야 합니다.
2. **시네마틱 선택 화면**: 중요한 사건이 발생하면 시간이 멈추고 화면 전체를 덮는 선택·결과 창이 등장합니다. 결과를 확인하고 계속 버튼을 눌러야 시간이 흐릅니다.
3. **소소한 사건 표시**: 상단 시간 바 아래에 최신 일상의 순간이 별도 띠로 표시되고, 기존 기록에도 계속 남습니다.
4. **연결의 상점**: 선택과 일상 경험으로 얻는 `연결 조각`으로 실질적인 아이템을 구매합니다. 배려·문화 이해 등 능력치는 재화가 아니므로 구매해도 줄어들지 않습니다.

### 상점 상품
- **현장 기록 노트 (16 조각, 영구)**: 학생/교직원의 역할에 맞는 추가 선택지 제공
- **대화 표현집 (18 조각, 영구)**: SPEAK에서 배운 표현을 선택했을 때 성공 확률 소폭 증가
- **관점 렌즈 (22 조각, 영구)**: 긍정적으로 전달된 선택의 문화 이해/배려 점수 소폭 강화
- **상황 관찰 티켓 (6 조각, 소모성)**: 사건 중 사용해 상황을 읽는 힌트 확인 (최대 9장)

## 기획상 유의사항
- 행동이나 배려를 단 하나의 '정답'으로 평가하지 않도록 결과에는 확률 요소를 유지했습니다.
- 학생이 베트남어를 모른다고 해서 곧바로 잘못된 사람처럼 묘사하지 않으며, 현지 직원이 안전·시설 규정을 임의로 바꿔야 한다고 안내하지 않습니다.
- 문화와 언어 표현은 현지 교직원 검토 및 당사자 동의 후 실제 서비스에 반영해 주세요.
- UI는 모바일에 대응합니다. 프런트엔드 단일 HTML 구현으로 데이터베이스·서버 계정·멀티플레이 기능은 없습니다.

## 코드 관리
- 모든 코드와 시나리오는 `index.html`에 포함되어 있습니다.
- `STAFF_STORIES`는 직무별 시나리오, `STAFF_AMBIENT`는 소소한 사건, `SHOP_ITEMS`는 상품, `renderStoryOverlay`는 선택 오버레이를 담당합니다.
- 구 버전 v3 세이브(`hanviet-link-v3`)를 현재 브라우저에서 읽습니다. v4 상점 데이터만 추가하며 계정 간 자동 이동은 지원하지 않습니다.
